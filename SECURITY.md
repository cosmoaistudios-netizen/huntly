# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

The Huntly project takes security and credential protection seriously. If you discover a security vulnerability or credential leak vector within Huntly:

1. **Do not open a public issue.**
2. Send an advisory email to `cosmoaistudios@gmail.com` with:
   - Description of the issue and potential impact.
   - Reproduction steps or proof-of-concept script.
3. You will receive an acknowledgment within 48 hours, followed by updates on the remediation roadmap.
4. Once a fix is verified and released, attribution will be credited in the release notes.
